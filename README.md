#功能实现
-
* 命令行交互式菜单：使用户可以通过输入，实现不同功能；让用户可以重复使用工具而无需重启脚本。
* 字符判断：实现字母与非字母、字母大小写的判断，方便分类处理。
* 移位计算：利用ord()和chr()转换字符和ASCII码，通过取模实现循环。
* 密钥归一：通过对密钥key取模，确保密钥可以被正确处理。
* 解密实现：直接调用加密函数，传入-key，简介且复用代码。
* 异常处理：捕获非数字错误，提高程序的健壮性。
